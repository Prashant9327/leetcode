## 📌 Auto-Sync with LeetCode

This repository is set up to automatically sync solutions directly from LeetCode upon every **Accepted** submission.

### How to Enable Auto-Commit:
1. Install **[LeetSync](https://chromewebstore.google.com/detail/leetsync-leetcode-to-gith/ppkbejeohfdipelk bigint)** or **[LeetHub v2](https://chromewebstore.google.com/detail/leethub-v2/mhanfgfclplhjademicggeioflhpfocm)** from the Chrome Web Store.
2. Click the extension icon and authenticate with your GitHub account (**Prashant9327**).
3. Set the target repository to:
   ```text
   Prashant9327/leetcode
   ```
4. Solve any problem on [LeetCode](https://leetcode.com) and click **Submit**.
5. Once your solution is **Accepted**, the extension automatically pushes the code, problem notes, and submission metrics to this repository!
